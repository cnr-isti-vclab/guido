(inner) resizeMap(minimap, sX, sY, point)

Ridimensiona la mappa e i marker. Il risultato sarà una mappa "allargata" in modo tale che il punto in cui è stato effettuato lo zoom rimanga fisso e i marker mantengano la dimensione originale.
Parameters:
Name Type Description

sX Number La quantità di ridimensionamento lungo l'asse X.
sY Number La quantità di ridimensionamento lungo l'asse Y.
point DOMPoint Il punto in cui centrare la ridimensione.
