(inner) markerClick(e, panoIndex, minimap)

Gestisce l'evento di click sul marker. L'operazione viene scelta in base alla modalità di editing attiva.
Parameters:
Name Type Description
e Event L'oggetto evento associato all'azione che ha innescato la chiamata alla funzione.
panoIndex Number L'indice del pano a cui è associato il marker all'interno del set corrente.
minimap MiniMap L'oggetto MiniMap a cui è associata la mappa.

(inner) markerHover(e, panoIndex, tooltips)

Gestisce l'evento di hover del marker. Scala temporaneamente il marker e mostra un tooltip con l'id del pano.
